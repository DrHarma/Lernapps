Ausgangssequenz (DNA-Matrizenstrang / codogener Strang):
3′–TAC TTC AAA CCG ATT–5′

Jede Mutation wird einzeln an der Ausgangssequenz durchgeführt. Positionen werden von links ab 1 gezählt. Bei Aufgabe 2b wird das neue A zur neuen Position 4 (also vor das bisherige T an Position 4).

1 · DNA verändern

Neue Base auf eine vorhandene Base ziehen = ersetzen. Auf eine schmale Lücke ziehen = einfügen. Vorhandene Base in das Löschfeld ziehen = entfernen. Alternativ: Palette anklicken, dann Base oder Lücke anklicken. Zum Löschen erst „Löschen“ wählen.

2 · mRNA transkribieren

Nutze die komplementäre Basenpaarung. Die Codesonne wird mit mRNA-Codons in 5′ → 3′-Richtung gelesen.

3 · Aminosäuresequenz bestimmen

Wähle pro vollständigem Triplett eine Aminosäure oder „Stopp“. Nach einem Stoppcodon „keine Translation nach Stopp“ wählen. Stopp ist keine Aminosäure. Die Zahl der Felder richtet sich nach deiner DNA; unvollständige Tripletts werden nicht übersetzt.

Codesonne

Von innen nach außen: 1. Base → 2. Base → 3. Base → Aminosäure. Einen äußeren Sektor antippen oder mit der Maus berühren, um ein Codon nachzuschlagen. Die Codesonne übernimmt keine Antworten.

Arbeitshinweise

  1. Ausgangssequenz zuerst bearbeiten.
  2. Mutation genau nach Aufgabenstellung setzen.
  3. mRNA komplementär bilden und ab dem Start in Tripletts lesen.
  4. Mit der Codesonne übersetzen.
  5. DNA-Veränderung und Translationsfolge getrennt benennen.
  6. Folgen begründet beschreiben.

Bei Rasterverschiebungen ohne Stoppcodon im gezeigten Ausschnitt bleibt die endgültige Proteinlänge offen. Ein verbleibender Rest von 1–2 Basen ist kein Codon.
