# Unterrichts-Apps

Sammlung interaktiver Unterrichts-Apps (Chemie, Biologie, MoLab, Sonstige), veröffentlicht über GitHub Pages.

- `index.html` – gemeinsame Startseite
- `chemie/07 … q2/`, `biologie/05 … q2/`, `molab/`, `sonstige-apps/` – Ordner für die Apps

Neue App ergänzen: HTML-Datei in den passenden Ordner hochladen und in `index.html` im Abschnitt „HIER NEUE APPS ERGÄNZEN“ eintragen.
